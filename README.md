> **This repository is archived (12 November 2026).** PCBKit's command line is installed with `curl -fsSL https://pcbkit.io/install.sh | sh`, or comes with the plugin [pcbkit-io/agent-plugin](https://github.com/pcbkit-io/agent-plugin). This tap is no longer updated.

# PCBKit Homebrew tap

```sh
brew install pcbkit-io/tap/pcbkit
```

`Formula/pcbkit.rb` is written by the release workflow of [pcbkit-io/cli](https://github.com/pcbkit-io/cli) at every release.
